1. Pilih file

Excel .xls atau .xlsx, maksimal 5 MB dan 500 baris data. Baris pertama adalah judul kolom.

2. Pengaturan untuk semua user baru dalam file ini

Role dan profil tidak ditebak dari jabatan. Pilih di sini, lalu sesuaikan per user lewat Kelola jika diperlukan.

Aturan import

  • Isi tab Data_User. Jika file hanya memiliki satu tab, nama tab bebas.
  • Nama perusahaan harus cocok dengan company aktif di aplikasi; Company ID juga diterima. Company tidak dibuat otomatis.
  • Satu orang di beberapa perusahaan ditulis pada beberapa baris dengan ID dan nama yang sama. Untuk user baru, baris perusahaan pertama menjadi default.
  • Seluruh baris milik ID yang sudah terdaftar, termasuk user nonaktif, dilewati. Tidak menambah membership atau mengganti data user tersebut.
  • Membership baru aktif, tetapi penggunaan bot tetap memerlukan whitelist aktif. Akses module diatur terpisah setelah import.
  • Gunakan nilai biasa, bukan formula. Jika ada data user baru yang tidak valid, seluruh import dibatalkan.
